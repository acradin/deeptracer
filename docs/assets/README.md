# Assets

이 폴더는 README 및 문서에서 사용하는 이미지/미디어 파일을 담습니다.

## 넣어야 할 파일

| 파일명 | 용도 | 상태 |
|--------|------|------|
| `logo.png` | 프로젝트 로고 (README 상단) | ⬜ 업로드 필요 |
| `demo.gif` | 사용 데모 애니메이션 | ⬜ 나중에 |
| `demo-thumbnail.png` | 데모 영상 썸네일 | ⬜ 나중에 |

## 로고 업로드 방법

GitHub 웹에서: 이 폴더로 이동 → **Add file → Upload files** → 로고 이미지를 `logo.png`로 업로드.

> `logo.png`가 업로드되면 README 상단에 자동으로 표시됩니다.
